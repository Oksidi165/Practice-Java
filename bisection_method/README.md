# Нахождение корня методом бисекции

## Поставленая задача:

> Разработать консольную программу на **любом языке программирования**, которая находит приближённый корень нелинейного уравнения методом бисекции (методом деления отрезка пополам).

## Итог выполнения задания:
Была разработна программа на языке `Java` которая использует метод бисекции для нахождения приближенного корня нелинейного уравнения.

Для решения была использована функция:

**`f(x) = x³ − x − 2`**

***
### Заданные начальные параметры:

*Отрезок:* **[1; 2]**

*Точность:* **ε = 0,0001**

***

### Примерный алгоритм работы:
1. Задаются границы отрезка `a` и `b`.
2. Находится середина отрезка `c`.
3. Вычисляются значения функции.
4. Определяется половина отрезка, в которой находится корень.
5. Выбранный отрезок снова делится пополам.
6. Действия повторяются, пока не будет достигнута заданная точность.
7. В консоль выводится найденный корень.
